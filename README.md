# JOVENS SEM LIMITES

Site para inscrição de corrida com:
- formulário de inscrição
- período de inscrições de 02 a 07
- pagamento via PIX
- envio de comprovante por WhatsApp
- área administrativa protegida
- painel com total de inscritos e status do pagamento

## Como rodar

### 1) Instale as dependências
```bash
pip install -r requirements.txt
```

### 2) Inicie o projeto
```bash
python app.py
```

### 3) Acesse
- Página principal: http://127.0.0.1:5000
- Área do administrador: http://127.0.0.1:5000/admin
